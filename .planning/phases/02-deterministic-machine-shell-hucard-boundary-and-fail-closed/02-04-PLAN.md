## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| content bytes to mapper | a bank index or offset from guest-side code must never read outside the 1 MiB array |
| synthetic fixture generator to repository | a generator must not leave ROM-like files in the tree |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-11 | Tampering | ds_mapper_read out-of-range bank or offset reading past the ROM array | high | mitigate | table indexed by size enum, bank 0x80 and above returns DS_MAP_UNMAPPED without touching the array, offset 8192 and above returns DS_MAP_BAD_OFFSET; accept_unmapped_banks asserts all 128 high banks; sanitizer preset reruns the cases in plan 06 |
| T-02-12 | Tampering | wrong SHA-256 giving a false content identity | medium | mitigate | NIST literals, one-million-a chunked feed, 21-length sweep against the host tool in the gate, length-in-bits rule verified at the 55 and 56 byte boundaries |
| T-02-13 | Information Disclosure | ROM-like bytes written into the tree by the generator | high | mitigate | images exist only on stdout of --emit and in memory; *.bin is gitignored and plan 05 rights-check default-denies any such file |
| T-02-14 | Tampering | expectation sharing code with implementation, giving a vacuous pass | high | mitigate | independent awk oracle with its own arithmetic and tag formula; the wrong-mirror toy must be shown red by the same case; ORACLE_RULE_TEXT_DRIFT guard |
