<artifacts_produced>
## Artifacts this phase produces (this plan's share)
- tests/controls mechanism: each tests/controls/NAME holds one C file named like the core source it replaces and an EXPECT file listing case ids (one per line) that must come out guest_failure. CMake discovers the directories and builds a toy runner target per directory from the core sources with the same-named file replaced.
- conformance-run controls mode (runs after the matrix inside the conformance stage): runs each toy runner against the same cases TSV, requires for every EXPECT id a RESULT line whose id and outcome fields are that id and guest_failure (awk field match, not a whole-line match) plus RUNNER_DONE; prints `CONTROL NAME RED_OK`, or `CONTROL NAME NOT_RED` (fails the stage), and exits 2 when an EXPECT file is absent or empty.
- Toy: tests/controls/wrong-mirror (mapper.c with the 384K rule changed to b and 0x3F; EXPECT lists accept_384k_banksig).
- Cases (REQUIRED): ref_size_8192 (len 8192, expect load.size_unsupported) and ref_size_512k (len 524288, expect load.size_unsupported, pins LED-LOAD-0004).
- Ledger: LED-LOAD-0004 (status open; disagreement lists MAME 0,1,2,3 repeated versus Beetle and Geargrafx banks 32 to 63 repeated for 512K and MAME special 192K versus modulo 24; the three sizes are refused; pinning_test TEST:ref_size_512k; withheld any claim about a 512K, 768K or 192K card; origin 02-CONTEXT D-44); listed in ledger/REQUIRED.
- SPDX (D-80): the toy C file and every new script and awk file carry the MIT OR Apache-2.0 two-line header; ledger entry and case TOML carry 0BSD.
