## Artifacts this phase produces (this plan's share)
- scripts/core-boundary-check CLI: `[--expect CODES] [--root DIR] [--cc CMD]`; scans ROOT/src/core/*.c; marker `STATUS core-boundary ok`; codes CB_INCLUDE, CB_COMPILE, CB_UNDEF_SYMBOL, CB_WRITABLE, CB_FLOAT, CB_NO_SOURCES (exit 2), CB_NO_SYMBOLS (exit 2).
- scripts/core-boundary.allow: SPDX comment lines, then names one per line; platform-limited entries written NAME then TAB then Darwin. Contents: memcpy, memmove, memset, memcmp for all; bzero and __chkstk_darwin (leading underscore stripped) for Darwin.
- Compile command (per source, standalone): -std=c11 -O0 -ffreestanding -nostdinc -isystem COMPILER_INCLUDE_DIR -I src/core -fno-common -fno-stack-protector -fno-pie -Werror=date-time -Wall -Wextra, plus -D_FORTIFY_SOURCE=0 on Darwin; COMPILER_INCLUDE_DIR from cc -print-resource-dir plus /include, else cc -print-file-name=include. Files that fail the include check are not compiled (so each control yields a deterministic code set on every compiler).
- Include rule: only stddef.h, stdint.h, stdbool.h, quoted ds_*.h and quoted *.def are allowed (limits.h resolves on clang and is still banned).
- Writable-symbol rule: Darwin uses nm -m sections (__DATA data, bss, common, thread, and the common marker); Linux uses nm -P types B b C D d G g V v u (not S s).
- Float rule: float or double tokens in comment-stripped source.
- Controls under tests/gate/core-boundary (mini-roots with src/core/*.c and EXPECT): time-include, limits-include, clock-call, env-call, alloc-call, global-counter, local-static, init-data, time-macro, float-use (EXPECT CB_FLOAT), ok-memset-stack (memset plus a 20 KB stack array), ok-const-tables.
- Stages (new): core-boundary, core-boundary-negatives. Selftest lines: mutation-core-boundary-allow, mutation-core-boundary-writable. Stage count after this plan: 35.
- Platform labelling: this Mac has only Apple clang and BWK awk; real gcc, mawk and gawk evidence for this checker comes first from the plan 21 container run (the first real gcc/mawk/gawk evidence on this Mac) and from CI, never from this plan.
- SPDX (D-80): scripts/core-boundary-check, scripts/core-boundary.allow and every control C file under tests/gate/core-boundary carry the MIT OR Apache-2.0 two-line header (the extended licence-check scans tests/**/*.c, so a missing header fails the `licences` stage).
