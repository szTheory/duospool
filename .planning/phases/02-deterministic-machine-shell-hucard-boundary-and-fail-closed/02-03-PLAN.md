## Artifacts this phase produces (this plan's share)
- conformance-run supervise CLI: `sh scripts/conformance-run supervise --ids FILE --out FILE [--wall N] -- CMD ARGS...`. Runs CMD with stdout to OUT under `perl -e 'alarm N; exec @ARGV'`. Normal exit: returns CMD's status. SIGINT or SIGTERM (trap lines carry the comment token rule-cancel-trap): kill CMD, append `RESULT ID cancelled assertions=0 evidence=signal:INT|TERM` for every id in the ids file that has no RESULT line in OUT, append `RUNNER_DONE n` (n = number of RESULT lines), print `CANCELLED signal:NAME n=COUNT`, exit 1. Wall expiry: kill CMD, print `HARNESS_WALL seconds=N` on stderr, exit 2.
- preflight: `PREFLIGHT_OK tool` lines, `PREFLIGHT_MISSING tool` and exit 2 on absence, marker `STATUS preflight ok`; `--tools LIST` (space-separated, `a|b` means either satisfies); default list: cmake ninja cc nm perl iconv awk git and sha256sum|shasum.
- outcome-sync codes: OUTSYNC_ROWS, OUTSYNC_NAME, OUTSYNC_ORDER; `--root DIR` for mini-roots (plan 06 adds the optional compiled-names input).
- scripts/check: flag `--timing` (combinable with --stage; prints `TIMING stage seconds` after each CHECK line and `TIMING_WARN stage` above 20 s, never a failure); every run writes `build/gate/results.tsv` (stage, verdict, seconds). Usage: `usage: sh scripts/check [--selftest [NAME] | --stage NAME] [--timing]`.
- Stages (new): preflight (first), cancel-controls, outcome-sync. Selftest lines: mutation-cancel-trap, mutation-outcome-sync.
- Stage count after this plan: 23 (baseline at phase start 18; plan 02 added ingest-controls and flatten-controls; this plan adds preflight, cancel-controls, outcome-sync).
- SPDX (D-80): scripts/conformance-run, scripts/preflight, scripts/outcome-sync and the stub scripts under tests/gate carry the two-line MIT OR Apache-2.0 header.
