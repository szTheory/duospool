<objective>
Add the machine facts a run record must carry: seeded power-on state (CORE-03), the canonical state digest, the full D-53 run record including the resolved profile identity (PROF-03), and the placeholder stepping that makes later interleave and perturbation tests able to fail (D-50, D-52, D-53, D-68, D-69).

Purpose: with no CPU in this phase, a stepping API that only counts would let a shared-state bug pass every determinism test. Evolving, seeded state is what gives the later liveness controls teeth.
Output: poweron, serial/digest and advance sources, the final record printer, two goldens, record-lint with controls, LED-PROF-0002.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host seed and policy to machine state | nondeterminism or host data must not leak into state |
| machine state to digest | a field missing from the digest hides a regression |
| record text to consumers | records are compared byte for byte and may be published |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-24 | Tampering | a state field omitted from the canonical digest | high | mitigate | digest_region perturbs every region of a live instance and requires a change; drop-region toy must be shown red; framing checked by an independent stream capture |
| T-02-25 | Tampering | host-dependent bytes (pointers, padding, wall time, paths) entering a record or digest | high | mitigate | explicit little-endian stream, zeroed instance, record lint (REC_PATH, REC_POINTER, REC_TIMESTAMP) with planted controls, goldens compared byte for byte |
| T-02-26 | Spoofing | a seed supplied under the zero policy or missing under the seeded policy | medium | mitigate | powerup_seed_required and powerup_seed_unexpected refusals with rows and a precedence pair |
| T-02-27 | Repudiation | placeholder state evolution read as a hardware claim | medium | mitigate | time_unit placeholder-cycles in every record; LED-PROF-0002 withheld list names the placeholder and the MPR constant |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | no package-manager installs in this plan |
</threat_model>
