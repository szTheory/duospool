<objective>
Complete and harden the refusal contract: the full matrix with fixed precedence, byte-level non-mutation, the no-heuristic proofs with a red toy, the no-leak proof, and the two ledger pin moves (CONT-01, CONT-02, CONT-03, PROF-02; D-43, D-45, D-46, D-66, D-67, D-70, D-72, D-56 redaction).

Purpose: the refusal matrix is success criterion 1. A reason that is "close enough" or a heuristic that agrees with an emulator source is the exact failure mode D-45 forbids, so each guess-shaped input gets a row and a toy that proves the row can fail.
Output: 48 new cases (73 in the directory), the precedence mutation, the heuristic-reverse rule (a toy generated from live boot.c), redaction cases and the pin moves. The 39 refusal rows are split into four task groups of fewer than ten items each (D-85).
</objective>
