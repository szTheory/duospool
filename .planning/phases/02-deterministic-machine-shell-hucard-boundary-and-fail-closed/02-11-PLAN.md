<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pull request metadata (title, branch, body) to workflow shell | attacker-controlled strings must not reach a run block |
| third-party action supply chain | a moved tag or compromised action runs with repository access |
| workflow permissions | excess token scope would let CI write to the repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-38 | Tampering | workflow injection through an untrusted expression in a run block | high | mitigate | WF_EXPR_IN_RUN and WF_UNTRUSTED_EXPR with an allowlist of non-attacker-controlled expressions; base SHA passed through env; untrusted-expr control |
| T-02-39 | Tampering | compromised or moved GitHub Action | high | mitigate | single action pinned to a full SHA (re-verified before commit), WF_UNPINNED_ACTION and WF_UNEXPECTED_ACTION, permissions contents read, persist-credentials false, monthly dependabot grouped update |
| T-02-40 | Elevation of Privilege | pull_request_target, workflow_run, secrets, self-hosted runners | high | mitigate | WF_FORBIDDEN_TRIGGER and WF_FORBIDDEN_KEY with controls; no secrets in the repository |
| T-02-41 | Repudiation | a workflow checker that accepts YAML it cannot parse | high | mitigate | restricted block-style subset; anything else is WF_UNPARSABLE exit 2; unparsable control; mutation-workflow-pin selftest |
| T-02-42 | Information Disclosure | CI logs echoing ROM-like content | medium | mitigate | the gate prints only ids, outcomes, sizes and hashes (plan 06 redaction case); rights-check and audit-history range run in CI |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | no package-manager installs; the one GitHub Action dependency is covered by T-02-39 |
</threat_model>
