<objective>
Prove CORE-01 and the fresh-process half of success criterion 3: instances do not share state, and the same inputs in a fresh process reproduce the same records (D-55), with both proofs shown able to fail.

Purpose: the core value is reproducibility. A determinism test that cannot fail on shared state or host-environment leakage is a repeatability claim without teeth.
Output: interleave cases, the shared-state toy control, scripts/determinism-run with controls, and the determinism stage.
</objective>
