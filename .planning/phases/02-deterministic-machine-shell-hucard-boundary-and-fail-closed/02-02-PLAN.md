## Artifacts this phase produces (this plan's share)
- Files: `tests/conformance/outcomes.def`, `scripts/conformance-ingest`, `scripts/conformance-flatten`, controls under `tests/gate/ingest/` and `tests/gate/flatten/`.
- Outcome tokens (lower snake case): pass, guest_failure, timeout, harness_failure, skip, cancelled, missing_artifact. X-macro row form: DS_OUTCOME(name), one per line.
- RESULT grammar: `RESULT {id} {outcome} assertions={n} evidence={ref}` with optional trailing `machine_time={n} stop={reason}`; id matches [a-z][a-z0-9_]*; final line `RUNNER_DONE {n}`. `ref` is a relative path (no leading slash, no dot-dot segment) or the supervisor source form `signal:INT` / `signal:TERM` (D-77).
- conformance-ingest CLI: `--results FILE --required FILE --inventory DIR [--outcomes FILE] [--root DIR] [--expect CODES]`; marker `STATUS conformance ok`. Each violation line is `CODE<TAB>class=NAME<TAB>detail`. Violation codes and classes (D-79(c)): OUTCOME_GUEST_FAILURE (guest_failure), OUTCOME_TIMEOUT (timeout), OUTCOME_HARNESS_FAILURE (harness_failure), OUTCOME_SKIP (skip), OUTCOME_CANCELLED (cancelled), OUTCOME_MISSING_ARTIFACT (missing_artifact; also emitted for every REQUIRED id with no RESULT line); harness_failure-class: ING_EMPTY, ING_NO_DONE, ING_DONE_COUNT, ING_BAD_LINE, ING_UNKNOWN_TOKEN, ING_DUPLICATE_ID, ING_UNLISTED_ID, ING_ASSERTIONS_ZERO (pass lines only: a non-pass line is already non-green, and the supervisor's cancelled lines legitimately carry assertions=0), ING_NO_EVIDENCE (any line), ING_REQUIRED_EMPTY.
- Counting rule that keeps each control to one code: a line with an unknown token, a duplicate id or an unlisted id still counts as a present RESULT line for the RUNNER_DONE arithmetic and for REQUIRED presence; an empty results file reports ING_EMPTY and the REQUIRED cross-check (so an empty file with a non-empty REQUIRED gives ING_EMPTY plus OUTCOME_MISSING_ARTIFACT for each id, and no ING_NO_DONE).
- conformance-flatten: stdout TSV rows `K`, file stem, table, key, type, value; last row `END` plus file count; codes FLAT_NO_INPUT, FLAT_NO_SENTINEL plus pass-through toml-subset codes (SYNTAX, DUP_KEY, BAD_STRING, ...). On any error stdout is empty and exit is 1.
- Stages (new): ingest-controls, flatten-controls. Selftest lines: mutation-ingest-skip-red, mutation-flatten-sentinel.
- SPDX (D-80): every new file under scripts/ and tests/ carries the two-line header MIT OR Apache-2.0 plus holder (C-style comment in outcomes.def); case TOML stubs under tests/gate carry a 0BSD header comment.
</artifacts_produced>
