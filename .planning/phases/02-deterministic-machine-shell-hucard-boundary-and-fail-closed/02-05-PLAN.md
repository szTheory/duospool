<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host to ds_boot | caller memory, request struct and content bytes are untrusted |
| run request to profile | bindings could try to override owner-selected fields |
| cases TSV to runner | hand-edited text drives which checks run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Tampering | misaligned, NULL or short caller memory cast to the instance | high | mitigate | memory_invalid is the first check; uintptr_t modulo and cap compare before any cast or write; rows in plan 11 exercise NULL, short cap and mem+1 under the sanitizer preset |
| T-02-08 | Elevation of Privilege | run-request binding overriding an owner-selected field or a value outside allowed | high | mitigate | resolve returns bind_closed_field and bind_not_allowed naming the field; resolve_bind_closed and resolve_bind_not_allowed cases; no defaults for open fields (open_unbound) |
| T-02-09 | Tampering | core instance mutated by a refused boot | high | mitigate | ds_boot takes no existing instance; a refusal writes only the result struct; the byte comparison and digest proofs land in plans 11 and 13 |
| T-02-10 | Tampering | runner trusting a truncated cases TSV | medium | mitigate | runner requires the END row and fails with a harness-class result otherwise; flatten prints nothing on error (plan 02) |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | no package-manager installs in this plan |
</threat_model>
