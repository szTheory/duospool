<objective>
Make fixtures and the required-test inventory fail closed, and calibrate that with the five named negative controls (FIX-02, FIX-04, D-58, D-59, D-60, D-72 pin resolution).

Purpose: a green gate that silently ran fewer tests, used an undocumented image, or accepted a wrong expectation is worse than a red one. Each of those failure modes gets a control that is itself judged by the real checker or the live runner.
Output: fixtures/manifest, scripts/fixture-check, scripts/inventory-check, mini-root controls, a deterministic timeout control, the named-controls stage and four new selftest mutations.
</objective>

## Artifacts this phase produces (this plan's share)
- Manifest files fixtures/manifest/ID.toml (0BSD SPDX header comment; ID equals the file stem; recipe name with hyphen or colon maps to ID by replacing each with an underscore, for example plain-256k to plain_256k and len:513 to len_513). - Named-controls stage prints NAMED_CONTROL NAME RED_OK for removed-required, missing-field, unlisted-fixture, wrong-literal, romlike-binary (the last drives the plan 05 planted-pce case) and fails on NOT_RED.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture generator to gate | the emitted bytes are hashed by an independent tool and compared with the manifest |
| REQUIRED list and case files to verdict | silently shrinking the required set would turn the gate green |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-34 | Tampering | a fixture used without documentation or with a changed generator | high | mitigate | FIX_UNLISTED, FIX_HASH_MISMATCH, FIX_STALE with controls; the generator spec string is part of the hashed recipe; independent host hash |
| T-02-35 | Tampering | REQUIRED list shrinking or case files deleted so a check silently disappears | high | mitigate | INV_REQUIRED_MISSING, INV_UNLISTED_CASE, INV_REQUIRED_EMPTY, removed-required named control, mutation-inventory-required-missing |
| T-02-36 | Spoofing | a wrong expectation accepted as a pass | high | mitigate | wrong-literal control through the live runner must be guest_failure and non-green in the ingest |
| T-02-37 | Repudiation | a verdict source that is the emulator's own output | medium | mitigate | FIX_BAD_VERDICT_SOURCE rejects duospool-output; only spec-literal, guest-computed or independent-script are accepted |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | no package-manager installs in this plan |
</threat_model>
