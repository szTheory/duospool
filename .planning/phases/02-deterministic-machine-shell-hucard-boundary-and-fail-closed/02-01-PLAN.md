<objective>
Refactor the gate's copy-pasted control loops into one `run_controls` helper before any new stage exists (D-58 prerequisite refactor, CONTEXT Claude's Discretion ordering constraint), proving the refactor changes nothing observable.

Purpose: every later plan adds a control family with one line instead of fifty. If the refactor silently changed behaviour, every later control would inherit a weaker gate, so equivalence is proved by transcript comparison and a selftest mutation, not by reading the diff.
Output: refactored `scripts/check`, a `--stage NAME` flag (needed by later plans for fast per-stage verification), and `tests/check/equiv.sh`.
</objective>
