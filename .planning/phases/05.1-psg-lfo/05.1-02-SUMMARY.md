  - Setup: d = 3 (bind.psg_tick_divisor=3), F1 = FLF = 1, CTL 1, TRG 0, select 1's table all $10, F0 = 1, so F0' = 1.

**The judge** (audiokinds.c au_rows_row, AK_LFO_DYNAMIC):
1. It takes the complete cycles between consecutive rising crossings and groups them into maximal runs of equal length.
2. Every run length must be in the set, with one exception: a single cycle of another length that sits between a run of A and a run of B.
3. Both lengths must occur.
4. No such cycle may sit at the window's edge.
5. Every interior set run must hold at least AU_LFO_MIN_RUN = 40 cycles.

AF0 reads A + 1. No switch instant is computed.
