Shared conventions for every script this plan creates:
- Line 1 is `#!/bin/sh` (awk files: no shebang). The next two lines are `# SPDX-License-Identifier: MIT OR Apache-2.0` and `# SPDX-FileCopyrightText: Copyright (c) 2026 The DuoSpool Authors` (D-01, D-31).
- `set -eu`, `LC_ALL=C; export LC_ALL`. Quote every variable and use `--` before filenames. Pass names to awk through ENVIRON, never `awk -v` (RESEARCH Pitfall 7). Do not use `eval`, awk `system()`, or `getline` from data-named files.
- Exit codes: 0 pass; 1 violation or unmet expectation; 2 usage or harness error. Never count exit 2 as an expected failure.
- POSIX awk only. No interval expressions `{n,m}`, no `\s`, no `[[:class:]]`, and none of gawk's `nextfile`, `length(array)`, `gensub`, `asort` (RESEARCH Pitfall 2).
- macOS `/bin/sh` is bash 3.2. Never put a `case` statement inside `$( )`; put it in a function defined outside the substitution (RESEARCH Pitfall 3).
- Every new script must pass `dash -n` and must also run under `/bin/sh`.
</context>
